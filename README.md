## 🟢 Node.js

Node.js is used for backend development and server-side JavaScript.

Example:

```js
import http from "http";

const server = http.createServer((req, res) => {
    res.write("Hello World");
    res.end();
});

server.listen(3000, () => {
    console.log("Server running on port 3000");
});
```
